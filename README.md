# CS255-DriverPass-Portfolio
CS 255 portfolio project including DriverPass business requirements, system design, and reflection.


## Reflection

The DriverPass project was designed for a client who wanted a system to help students prepare for their driving exams. The system included features such as lesson scheduling, package purchasing, practice tests, and account management.

One thing I did particularly well was organizing the requirements and designing the system for multiple users such as students, instructors, employees, and administrators.

If I could revise one part of my work, I would improve the UML diagrams by making them more detailed and visually polished.

I interpreted the user’s needs by reviewing the client requirements and creating features that directly supported those goals. Considering user needs is important because software should solve real problems effectively.

My approach to designing software is to first understand requirements, identify users, and create diagrams and planning documents before development begins. In the future, I will continue using structured analysis and design methods.
